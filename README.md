# Thrift Flip website

The public site with the privacy policy, published by GitHub Pages from the
`zealot-SEAlot/thrift-flip` repository:

- Home: https://zealot-sealot.github.io/thrift-flip/
- Privacy policy: https://zealot-sealot.github.io/thrift-flip/privacy/

The source lives here in `site/`; to publish a change, copy this folder's
contents into that repository and push. The policy text follows
`docs/launch/privacy-policy.md` and `docs/launch/data-inventory.md`; change
those first.

`app-ads.txt` only counts at the root of the developer website's domain, so
before production either publish this site as the root user site or move it
to a custom domain.
